# @pp/ui 可访问性对照清单

M2 Overlay 族（Modal/AlertDialog/Select）基于 Base UI 1.9 headless 底座，本清单对照
WAI-ARIA Authoring Practices 逐项记录「底座提供 / 本库补齐 / 消费方责任」三栏归属。
新组件入库前按此清单过一遍；标注 ⚠ 的项在试点/迁移时人工验证。

## Modal（桌面 Dialog / 移动 Drawer）

| 项 | 归属 | 说明 |
|---|---|---|
| `role="dialog"` + `aria-modal="true"` | 底座 | Base UI Root `modal` 默认 true |
| 焦点陷阱（Tab 不出弹窗） | 底座 | modal=true 自带 trap |
| 打开时焦点进入 / 关闭时焦点归还触发源 | 底座 | Popup `initialFocus`/`finalFocus` 默认行为 |
| 页面滚动锁定 + 外部指针禁用 | 底座 | modal=true 自带（替代 Konsta `touch-move` hack） |
| Esc 关闭 / 点 backdrop 关闭 | 底座 | `disablePointerDismissal` 可关 |
| 标题接线 `aria-labelledby` | 本库 | `Modal.Heading` → `Dialog/Drawer.Title`（h2） |
| 关闭按钮可读名 | 本库 | `Modal.CloseTrigger` 固定 `aria-label="关闭"` |
| 嵌套弹窗（AlertDialog 开在 Modal 内） | 底座 | 原生支持，子级不重复渲染 backdrop |
| ⚠ 移动抽屉滑动手势与滚动区冲突 | 本库 | `Modal.Body` 带 `data-base-ui-swipe-ignore`；试点验证长表单滚动 |
| ⚠ 移动端软键盘顶起表单 sheet | 消费方 | 需要时包 `Drawer.VirtualKeyboardProvider`（`--drawer-keyboard-inset` 带 0px 回退） |

## AlertDialog / ConfirmDialog

| 项 | 归属 | 说明 |
|---|---|---|
| `role="alertdialog"`（要求用户响应） | 底座 | Base UI AlertDialog 专用角色 |
| 标题/描述接线 | 本库 | `Heading` → Title；`Body` 内容经 Description 语义由底座挂接 |
| 初始焦点落在安全操作（取消） | 底座+消费方 | Base UI 默认聚焦首个可交互元素；⚠ 破坏性操作试点验证 |
| busy 时禁止关闭 | 本库 | `ConfirmDialog` 的 `onOpenChange` 拦截 + 取消按钮禁用 |

## Select / ListBox

| 项 | 归属 | 说明 |
|---|---|---|
| trigger `aria-haspopup="listbox"` / `aria-expanded` | 底座 | Base UI Select 自带 |
| 选项 `role="option"` + `aria-selected` | 底座 | Item/ItemIndicator |
| 键盘导航（↑↓/Home/End/Typeahead） | 底座 | typeahead 用 Item `label`（本库映射自 `textValue`） |
| 触发器可读名 | 本库+消费方 | `Select` 的 `aria-label` 透传 Trigger；**消费方必须提供**（桌面 16 处现状均有） |
| 空值占位样式 | 本库 | `data-placeholder` 态 text-muted |
| 弹出层定位/翻转/可用高度 | 底座 | Positioner `side="bottom"` + `--available-height`；⚠ 试点验证窗口底部长列表 |

## 通用

| 项 | 归属 | 说明 |
|---|---|---|
| 焦点可见环 | 本库 | 所有交互组件 `focus-visible:outline-2 outline-focus` |
| 禁用态 | 底座+本库 | `data-disabled`/`disabled` + `opacity-50 cursor-not-allowed` |
| 动效降级 | 本库 | ⚠ `motion-reduce` 变体尚未统一加（M3 随 toast/动画打磨一起做） |
| 色彩对比 | 本库 | 令牌值镜像 HeroUI（已过其对比度设计）；新增令牌须保持 |
