## 真实运行与浏览器

独立本机 Hub + /tmp 临时 SQLite，通过真实 HTTP 接口及 agent-browser 验证：

- 启动日志自动写入并展示在系统日志列表。
- 节点日志夹具通过真实接口返回节点名称，页面切换正确，长消息支持展开和换行。
- 浏览器中断请求模拟失败：显示加载失败提示，不误报为空记录；恢复后可重新读取。
- 筛选、刷新和类型选择控件可操作；首页配置每 15 秒刷新，其他页不轮询。

夹具仅写入临时数据库。首次文本 UUID 导致解码失败，改为 SeaORM SQLite 使用的
16 字节 BLOB 后返回 200；此为夹具格式问题，未调整业务代码绕过。

## 限制与部署边界

线上仅执行只读版本、服务状态与计数查询，尚未更新或重启服务。
首次升级需同时发布 Hub 与管理 Web，旧 Hub 不支持 kind=agent；旧 Agent 记录仍可读取，
新 Agent 才采用共享结构化采集与全局过滤。既有留存为系统日志 30 天、节点日志 7 天。
有界队列与有限退出等待不保证故障时零丢失；脱敏覆盖常见模式，不能识别任意自由文本秘密。
既有终端调试日志不由数据库脱敏层改写。PEM 文件保持 Git 忽略，未写入记录或提交。
